# Inspiration and provenance

The initial concept came from a user-provided checklist accompanying
[a post by @gbauzap](https://x.com/gbauzap/status/2107579815226220921): apps can look
finished while missing everyday launch basics. The skill, checklist and follow-up
guidance are original Luodaint material under the toolkit's [MIT license](../../LICENSE).
No upstream skill, executable code, media or verbatim post text is bundled.

The workflow extends that idea with project/surface detection, evidence and unknowns,
milestone-based priorities, conditional capability checks and optional `TODO.md`
tracking. It covers public web pages, interactive/internal applications, APIs/workers,
mobile/desktop products and developer tools without imposing web requirements on
every project. This is not an upstream import with an automatically replaceable
source revision.
